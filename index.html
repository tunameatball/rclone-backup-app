rclone backup

A personal OAuth client used by one person to back up files to their own Google Drive.

What this is

This page exists to satisfy Google's OAuth consent screen requirements for a personal-use application. The application is an installation of rclone, an open-source file transfer tool, running on the owner's own home server.

What it does

It uploads backup archives from a self-hosted Git server to the owner's own Google Drive on a daily schedule. It uses the drive.file scope, which limits access to files the application itself creates.

Who can use it

Only the owner. This application is not distributed, not offered as a service, and has no other users.
