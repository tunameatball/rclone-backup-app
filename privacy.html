Privacy policy

Last updated: 2026-10-17

Scope of this application

This is a single-user, personal application. It is an installation of rclone running on the owner's own home server. It is not distributed to anyone and has no users other than the owner.

What data is accessed

The application authenticates to the owner's own Google Drive account using the https://www.googleapis.com/auth/drive.file scope. This scope grants access only to files that the application itself creates. It cannot read or modify any other file in the Drive account.

What data is collected

None. The application collects no personal data, has no analytics, no server-side component that receives user data, and no third-party integrations. It only uploads the owner's own backup archives to the owner's own Drive storage.

What data is shared

None. No data is transmitted to any party other than Google Drive, which is the owner's own storage destination.

Data retention

Backup archives uploaded by the application are retained in the owner's Drive for 30 days and then deleted automatically by the application.

OAuth credentials

The OAuth refresh token is stored locally on the owner's own server, readable only by the owner's account. It is not shared or transmitted elsewhere.

Contact

This application is maintained by its sole user. Inquiries can be directed to the support email configured on the Google OAuth consent screen.
